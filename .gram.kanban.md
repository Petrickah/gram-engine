#### Task 2.w — A denoiser for the ray tracer
<!-- id: task-1794787200000-7 -->
Idea (2026-11-19): while anything moves the accumulation restarts every frame, so the image is one ray per pixel (ugly noise), and FSR 1 makes it worse (EASU keeps noise as edges, RCAS sharpens it). Real-time path tracers fix that with (1) temporal accumulation with reprojection (keep the history while moving, moved to where each point was last frame, from motion vectors or from depth and the camera's motion) and (2) a spatial denoiser guided by auxiliary images, so it smooths noise but not real edges. Plan: the ray tracer also writes normals and albedo (it already writes depth), then an SVGF-like filter (Schied et al. 2017, *Spatiotemporal Variance-Guided Filtering*: temporal accumulation, a variance estimate, a few à-trous wavelet passes weighted by normal/depth/luminance differences), all compute or post-process passes, working on every device (Mac included). A quick first experiment showing the trade-off: an exponential average (a fixed alpha such as 0.1) instead of a reset on motion, which trades noise for ghosting trails until reprojection exists. The other route to clean real-time images is hybrid rendering (rasterize what the camera sees, trace rays only for shadows, reflections, indirect light): Wave 3.

Idea (2026-11-19), from the BVH measurements: the ray tracer is GPU-bound per pixel (a smaller window raises the FPS; Debug and Release are within a few FPS), so fewer pixels is the lever. #### Task 0.4 — `gram build --ci`
<!-- id: task-1789300000000-4 -->
`gram build --ci` iterates every entry in a module's `targets` (currently `linux`/`windows`, via `x86_64-w64-mingw32-g++`/`rustc --target x86_64-pc-windows-gnu`) and places each binary in `../builds/<project>_<version>_<target>/<binary>` (sibling to the project dir). A plain `gram build` (no `--ci`) only ever builds for the host it's run on, ignoring the rest of `targets`. Simplified from the original `<date>-<commit>` layout — dropped since there's no actual CI pipeline consuming these artifacts yet (see CLAUDE.md's "No CI/CD until..." non-goal); revisit if/when one exists.
